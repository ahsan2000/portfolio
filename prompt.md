## 1. What it is

A one-page dark film portfolio for an editor / VFX artist. Black ground `#090909`, warm-white type `#f2efeb`, crimson accent `#e32b3c`, film grain overlay, thin section rules, oversized red condensed lettering behind a cut-out portrait. Fonts: **Anton** (display), **Manrope** 400–800 (body), **Caveat** 400/500 (handwritten accent), loaded from Google Fonts by `index.html`.

Sections in order: sticky header → Hero (giant `PORTFOLIO` lettering, portrait, intro, stats, CV link) → Selected work (featured three, then the full archive with category filters, search, load more, project dialog with video / still / 3D render stages, and the brand-logo strip) → Recognition & Awards → Breakdown (before/after slider) → About (education, skills, process, quote) → Journey (experience accordion, milestones) → Contact (links, reel card, WhatsApp brief form) → footer.

Motion (all Framer Motion, all inside `src/app.jsx`): global easing `[0.22, 1, 0.36, 1]`; reveal-on-scroll `y 32 → 0`; scroll-linked hero parallax; magnetic buttons (`stiffness 220, damping 20`); spring reading-progress bar; auto-scrolling brand rail; animated filter underline with `layoutId`; dialog spring-in. A header **Motion** toggle (saved in `localStorage` as `renando-motion`) and `prefers-reduced-motion` switch every non-essential animation off. No loader, no scroll hijacking.

Responsive: breakpoints at 1100, 800, 600 and 370 px (`max-width`) and 1600 px (`min-width`), plus `(hover:none)`. No horizontal overflow from 320 px up. Touch targets at least 44 px.

function Reveal({ children, className = '', delay = 0, as = 'div' }) {
  const enabled = useContext(MotionContext);
  const Component = motion[as];
  return <Component className={className} initial={enabled ? { opacity: 0, y: 32 } : false} whileInView={{ opacity: 1, y: 0 }} viewport={{ once: false, amount: 0.12 }} transition={{ duration: enabled ? 0.75 : 0, delay, ease: EASE }}>{children}</Component>;
}

function MediaImage({ src, alt, className = '', priority = false, ...props }) {
  const [state, setState] = useState('loading');
  const imgRef = useRef(null);
  useEffect(() => {
    const img = imgRef.current;
    // Cached images can finish before React attaches onLoad.
    setState(img?.complete ? (img.naturalWidth ? 'loaded' : 'error') : 'loading');
  }, [src]);
  return <span className={`media-image ${state} ${className}`}>
    {state === 'error' && <span className="image-fallback"><span className="display">R.</span><span>Pratinjau tidak tersedia</span></span>}
    <img ref={imgRef} src={src} alt={alt} loading={priority ? 'eager' : 'lazy'} fetchPriority={priority ? 'high' : 'auto'} width="960" height="600" onLoad={() => setState('loaded')} onError={e => {
      if (e.currentTarget.src.includes('maxresdefault.jpg')) e.currentTarget.src = e.currentTarget.src.replace('maxresdefault.jpg', 'hqdefault.jpg');
      else setState('error');
    }} {...props} />
  </span>;
}

function Magnetic({ children, className = '', ...props }) {
  const enabled = useContext(MotionContext);
  const x = useSpring(0, { stiffness: 220, damping: 20 });
  const y = useSpring(0, { stiffness: 220, damping: 20 });
  return <motion.a className={className} style={{ x, y }} onPointerMove={e => {
    if (!enabled || e.pointerType !== 'mouse') return;
    const r = e.currentTarget.getBoundingClientRect();
    x.set((e.clientX - r.left - r.width / 2) * 0.12); y.set((e.clientY - r.top - r.height / 2) * 0.2);
  }} onPointerLeave={() => { x.set(0); y.set(0); }} {...props}>{children}</motion.a>;
}
